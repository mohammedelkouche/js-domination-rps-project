# Rock Paper Scissors (JS Domination)

A simple browser-based Rock, Paper, Scissors game built with JavaScript. The game is played using pop-up prompts, while all scores and round results are displayed in the browser console.

## How to Play
1. Open the game page in your browser.
2. Click **Let’s get handsy!** to launch the game.
3. When prompted, enter your choice: Rock, Paper, or Scissors.
4. Open the browser console (press F12, or Ctrl+Shift+J / Cmd+Option+J) to see the scores and round results.
5. The first to reach 3 points wins!
